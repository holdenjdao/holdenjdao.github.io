Dori — Accessible K-12 Learning Platform

🥉 3rd Place Minds and Machines AWS Hackathon · Sep 2026

A practice platform for students with IEPs and 504 plans, built around one shared plan for the learner, the teacher, and the family. The learner model is deliberately not an LLM — item-aware Bayesian knowledge tracing (KT-IDEM) in NumPy with next-question selection by maximum Fisher information, so any claim about a child's learning stays inspectable. Written content comes from RAG pipelines over an approved corpus, with Claude on Amazon Bedrock using forced tool use so replies are typed objects and every citation is verified against its source. Eight collaborative games run over a shared WebSocket room, and no identity ever reaches a model. Built to WCAG 2.2 AA with read-aloud, word-level highlighting, and no numeric score shown to a child.

CareCart — Community Health Request System

🥈 2nd Place Intermountain Health Generative AI Hackathon · Mar 2026

An intake and fulfillment system for a children's community health team, replacing an inbox and a spreadsheet. Schools, clinics, and nonprofits request free safety materials and event support through one bilingual form; staff get a single queue where each request arrives already triaged. Claude reads every submission alongside live inventory and returns a structured classification — priority weighed across staffing cost, lead time, stock, and audience scale, plus a fulfillment path and a service-area check — with its reasoning shown so a coordinator can override it in one dropdown. The scoring criteria are written once and shared between the model's prompt and the UI, so what staff read is exactly what the model was told. Ships with analytics, inventory tracking, generated calendar invites, and CSV export.

Weather Satellite Imaging Receiver

RF · DSP · Ground Station

A DSP pipeline built in GNU Radio and CST Studio that filters, demodulates, synchronizes, decodes, and reconstructs METEOR M2-4 weather-satellite transmissions into Earth imagery. The physical ground station runs on an RTL-SDR with a hand-built V-dipole antenna, FIR filtering, and FM demodulation — achieving >90% successful image reconstruction across 5 continents.
