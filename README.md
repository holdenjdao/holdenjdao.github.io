# holdenjdao.github.io

Personal portfolio of Holden Dao — live at [holdenjdao.github.io](https://holdenjdao.github.io).

Plain static site: no build step, no framework.

- `index.html` — all content
- `styles.css` — single-column reading layout, light and dark
- `script.js` — light/dark theme toggle

## Local preview

Any static server works, e.g.:

```
python -m http.server 8756
```
